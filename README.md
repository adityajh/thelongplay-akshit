# The Long Play

Marketing site for **The Long Play** — a year-long music program for children 7–14 in Pune, led by Akshit Deshmukh.

- `index.html` — home (one-page site)
- `offers.html` — fees & options (served at `/offers`)
- `img/` — photography

Static site. Deployed via Vercel. Tagline: *A relationship with music that outlasts the lessons.*
